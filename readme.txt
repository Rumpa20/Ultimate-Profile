[b]Ultimate Profile 1.0[/b]
Author: Rumpa | License: BSD 3-Clause | For: SMF 2.1.8 (2.1.x)

Adds a profile card to every member's Summary page and a new
"Ultimate Profile" page under Profile > Modify Profile, where members set:
 - Tagline and mood
 - About me (BBCode)
 - Cover image URL and accent color
 - Twitter/X, Facebook, Instagram, YouTube and GitHub links, Discord name
 - Card style: Classic, Dark, Gradient or Minimal
 - Profile view counter (once per visitor session)
 - Recent visitors list (visible to the profile owner and staff only; members can opt out of being recorded)
 - Automatic badges (staff, membership age, post count, popular profile)
 - Buddy list control: see your buddies (with mutual marker), remove selected or all, add by name,
   and choose who can see your buddies on your card (everyone / only buddies / only me)

[b]Settings:[/b] Admin > Configuration > Modification Settings
(enable, count views, max About length, visitors, badges, buddies).
[b]Permissions:[/b] uses the standard "Edit own/any profile (extra)" permissions.

The mod is hooks-only: no source or template files are edited.
